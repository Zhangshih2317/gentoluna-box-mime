## 运行

在项目目录执行：

```powershell
python run_box_mime_taught.py
```

默认只读预检，不切模式、不改速度、不下发运动。真正执行使用：

```powershell
python run_box_mime_taught.py --execute
```

执行模式会重新读取反馈、检查故障，核对已验证路径缓存，并检查当前回 HOME 小段后开始动作。
默认不再重复约73秒的整套碰撞计算。
缓存 `points/BOX_MIME_GEOMETRY_CACHE.json` 绑定程序源码、URDF、碰撞网格、
碰撞检查代码/配置/本地库及末端变换；变化时拒绝复用，不自动转入长时间重算。
厂家FK仍在启动时核对。需要重新生成缓存时用 `--prepare-cache`，
它只做离线模型计算，不连接机器人控制器；`--full-preflight` 可显式重算完整路径。
FXPlatform 等其他控制客户端需要已断开。控制器速度倍率为20%，加速度倍率保持5%。
连续版以50 Hz下发位置，每个完整动作阶段使用一条五次平滑曲线。
取消每0.49°的小段停靠、阶段内部到位等待和阶段之间的静止采样等待。
保持原点位与关节空间路径，阶段衔接处速度、加速度平滑降至零。
阶段末持续发送目标，误差不超过0.03°、双臂/身体速度不超过0.15°/秒，
连续三个不同反馈帧确认后继续；最多等待5秒，超时停止。
输入回显匹配最近0.25秒内已发送的完整指令，容许编码器量化误差0.05°；
不会把最新目标与上一帧的输入回读直接判为错误。
整姿态须位于最近2.5秒已发送路径区间的0.12°内，使用所有轴共享的路径进度。
这是有界的协调跟随滞后，不允许各轴任意滞后或只检查最终点位。

## 动作顺序

1. 对齐 HOME：小幅张臂先收臂；本次全张臂浅蹲中断姿态先站直再收臂。
2. 双臂张开。
3. B2、B3、B4 联动浅蹲，维持起始上身方向。
4. 双臂空载合抱。
5. 保持合抱，身体站回 HOME 高度。
6. B6 沿示教的负方向相对 HOME 转动 45°。
7. 保持站高，双臂张开模拟释放。
8. 双臂回 HOME。
9. B6 回 HOME，复核全身位置；BODY 转 IDLE，释放 SDK 连接。

开始时要求头部和 B1～B5 接近 HOME。双臂J3允许在HOME向外张开2°内，
其余手臂关节偏差不超过0.05°；因此可从本次约1.2°张臂中断位置自动收臂回HOME。
这不是任意姿态恢复。双臂回位在身体回位之前执行，各自单独检查路径。
B6 允许在 HOME 附近 2°内，
或在已记录的转腰示教点附近 0.05°内；其他未知姿态拒绝运行。
头部保持实测值，不发送头部命令；其与 HOME 差异必须在 0.05°内。
正常完成自动回 HOME；异常先停止，不继续回 HOME。
状态100/错误110仍拒绝启动，不自动清错；先在示教端恢复正常控制状态，
退出其他客户端后再运行，程序才会执行前置回HOME。

新增恢复范围只接受双臂J3在全张开18°附近0.05°内、B3相对HOME下蹲
大于0°且不超过3°、BODY在示教联动线上0.05°内、B6在HOME附近0.05°内。
其余手臂关节仍须在HOME附近0.05°内。先保持双臂站直，再收臂；
这两段在每次启动时进行模型碰撞采样，不复用主路径缓存来跳过恢复段检查。

转腰中断恢复仅接受站姿、双臂在合抱点附近0.05°内、腰部在HOME至负45°之间；
先保持合抱回腰，再收臂，恢复路径在启动时逐点核对。
双臂J5～J7等其他关节发生大幅变化时拒绝自动恢复。
