# 带夹爪测试与停止策略待核实项

日期：2026-11-12。

## 用户确认

- 手臂已经稳住。
- 左右夹爪各不超过2公斤。这是上限，不是实际质量或重心标定值。
- 测试希望允许2度以内的偏差，允许1～2秒跟随延迟，实际到点再继续下一阶段。
- 不希望普通软件偏差触发全身软件急停而失去手臂保持。
- 后续补充：双指夹爪、TCP向前延长100毫米，控制器没有配置负载和重心。
  “向前”的法兰坐标轴及工具姿态尚未明确，不能据此写入某一轴的TCP数值。
  不再将型号名称作为必需信息；实际安装几何、质量和重心仍需核实。

这些要求尚未作为带载实机安全参数批准。2度必须明确是躯干俯仰角度和误差、
单轴跟随误差还是路径偏差；不能把三者混为同一阈值。

## 已核实的故障路径

`evidence/box-mime-taught-20261112-152431.jsonl`：
下蹲时触发 `Torso pitch compensation mismatch`。
该检查比较B2+B3+B4实测和与命令和，当前阈值0.2度，并不是下蹲幅度限制。
统一异常处理调用 `emergency_stop(11)`，范围包含ARM0、ARM1和BODY。
约2秒后没有取得足够的连续静止反馈，记录 `stop_unconfirmed` 并断开SDK。
没有记录足以确认电源、驱动使能或制动器物理状态的数据。

## 现场接口核查

检查了现场 `GentoRobot.py`、`C_SDK/L1Robot/L1Robot.h` 和统一控制层：

- `runtime_stop_traj` 的说明只承诺停止轨迹执行。
- `emergency_stop` 的说明只描述指定对象的软件急停。
- `config_brake_lock` 提供轴制动锁定接口，但没有带载停止/使能切换的操作时序说明。
- 统一控制层普通停止包装的是 `stop_trajectory`；这不能证明它适用于当前50Hz位置流。
- `runtime_set_tool_d` 的文档需要质量、重心和惯量等10个参数；
  不能仅凭“各不超过2公斤”构造全部参数，也不能将工具位姿矩阵当作负载配置。
- 再次读取现场源码确认：`runtime_set_tool_k` 接受
  `[x, y, z, rx, ry, rz]`，而 `runtime_set_tool_d` 接受
  `[mass, com_x, com_y, com_z, Ixx, Ixy, Ixz, Iyy, Iyz, Izz]`。
  这两份接口注释及L1头文件未明确量纲、重心参考坐标系或惯量约定，
  也未说明Position模式下的使用与持久化规则，暂不写入猜测值。
  用户提供的100毫米是TCP偏移，不是已测得的重心。

未调用上述停止、制动、使能或负载写入接口；未为诊断重新连接机器人控制SDK。
只有SSH读取现场源文件。

2. 厂家确认位置流控制下的受控停止与持续保持方法，以及通讯断开/驱动故障时的制动行为。

4. 模型加入夹爪几何，验证期望容差内的运动和双臂间隙，再验证带载停止保持。

当前两个运动入口继续禁用。未实现或验证新的带载保持方案；
不得将本记录或用户请求的2度直接作为恢复旧执行入口的依据。
尚无证据能把此次掉电报告归因于未配置负载；已证实的是程序发送全身软件急停、
随后未确认停稳。负载参数修正不能单独保证急停或断电时的机械保持。

## 2026-11-12 离线候选实现

新增 `tools/motion_wait_policy.py`，尚未接入 `MimeRunner` 或任何SDK执行入口。
原执行入口仍有带载锁，原控制器异常处理未被候选代码替换。

候选行为：

| 条件 | 行为 |
| --- | --- |
| 沿动作路径短时滞后 | 继续生成平滑目标；阶段末等待实际到位 |
| 移动轴路径偏差超过2度，或B2～B4角度和偏差超过2度 | 保持最后已发送目标，冻结轨迹时间 |
| 普通偏差恢复且未进入人工等待 | 恢复推进，扣除暂停时间，不追赶积累的时间 |
| 阶段末实际误差不超过0.2度且速度不超过0.15度/秒 | 连续3个新反馈帧后完成；HOME仍要求0.05度 |
| 等待达到10秒 | 锁定人工处理等待，继续保持最后目标，不自动进入下一阶段 |
| 未命令轴漂移、关节硬限位、非法数据、调度异常 | 硬故障继续向外层报告，候选代码不覆盖安全处置 |

候选驱动只接受 `read_checked` / `send_checked` 适配器，故障、心跳、碰撞、
输入回显和实际带载停止必须由经验证的外层控制器实现。
该驱动没有SDK连接、急停、IDLE、抱闸、重新使能或断开连接调用。
因此“候选逻辑不发急停”不能被表述为“实机不会掉电”。
2度路径容差是待验证参数，不代表原裸臂离散碰撞检查覆盖了该偏差范围。

120项离线回归通过，新增10项覆盖2度边界、普通偏差保持、2秒延迟、
10秒人工等待锁定、重复帧不算到位、HOME精度、硬故障、轨迹时钟冻结，
以及候选实际循环在2秒反馈延迟下完成一个下蹲阶段。
未发送任何机器人运动或模式切换指令，未恢复实机执行权限。
