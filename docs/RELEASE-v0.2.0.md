# v0.2.0 完整开发文档与双夹爪程序

覆盖2026-11-10至2026-11-16留存资料：VR交接、SDK接入、双臂HOME、
BODY人工示教、单轮/六轮搬箱模拟、回HOME、双USB夹爪、网络、电量屏与语音。

本次新增可配置的 `run_grippers.py`，提供双爪张开/闭合/只读状态菜单，
默认速度10%、力矩30%，动作完成后保持。SSH、USB身份、厂家SDK路径
由下载者填写；支持USB枚举、远端独立环境安装、本机配置检查。

从 `README.md` 和 `docs/INDEX.md` 阅读。夹爪安装见 `docs/GRIPPERS.md`，
搬箱/回HOME见 `docs/SETUP.md`。完整ZIP包含源码、文档、样例点位、
脱敏日志和历史归档；无需原开发电脑的个人目录。

厂家SDK、专有碰撞/标定/模型、上位机安装包、密码与私钥不包含在下载中。
提供自己的依赖和设备配置后方能连接运动；仅阅读和离线测试无需机器人。
夹爪B=0x1000例外在公开版默认关闭，只能按自己设备的厂家结论开启。

现场成功记录来自原现场版本，公开部署改造仅做离线验收，没有为发布驱动机器人。
